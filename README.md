## Stock Trend Prediction (📈 / 📉)  
> **Status:** Under Development 🚧

An end-to-end applied data science tool that predicts whether a stock will close higher or lower on the next trading day using historical market data.

### Machine Learning Design
* **Algorithm:** Random Forest Classifier
* **Framing:** Binary classification (1 = Up 📈, 0 = Down 📉)
* **Features:** Moving averages (`MA_20`, `MA_50`), market volatility, and daily percentage returns.

### Cloud Deployment & MLOps (AWS SageMaker)
The project aims to practice and implement production MLOps workflows with AWS
